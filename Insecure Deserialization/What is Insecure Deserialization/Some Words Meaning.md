1. **Library**: Yeh ek set of pre-made code hota hai jo developers apne project mein use karte hain taake kaam jaldi ho. Jaise ek toolbox jisme alag-alag tools hote hain. Example: PHP mein `Guzzle` library HTTP requests ke liye use hoti hai.

2. **Dependencies**: Jab ek library ya code dusre libraries pe depend karta hai, unhe dependencies kehte hain. Jaise agar ek app chalane ke liye 5 aur libraries chahiye, to woh uski dependencies hain.

3. **Data Tamper**: Jab koi attacker data ko beech mein badal deta hai (jaise tere parcel mein patthar daal diya), usse data tamper kehte hain. Example: Ek form ka data hack karke malicious code daal dena.

4. **Generic**: Yeh general ya common cheez ke liye bola jata hai, jo specific nahi hota. Jaise generic serialization ka matlab hai standard serialization jo koi bhi object ke saath kaam kare, na ke sirf ek specific type ke saath.

5. **Ruby**: Yeh ek programming language hai, jaise PHP ya Python. Iska use web development mein hota hai, aur isme serialization ko "marshalling" kehte hain.
